# Design system

The reference is translated into a premium ice-blue interface with navy typography, bright blue primary actions, restrained glass surfaces, realistic elevation and format-colored icon tiles.

## Tokens

- Primary: `#1677F2`
- Navy: `#0A1F54`
- Background: `#F2F7FF`
- Secondary text: `#44638C`
- Success: `#00A67D`
- Error: `#E5484D`
- Radius: 12–28 px according to hierarchy

Mobile uses a four-destination bottom bar. Desktop uses a persistent sidebar and purpose-built grids instead of stretching a phone canvas. The smallest supported layout is 320 px. Animation respects `prefers-reduced-motion`.
